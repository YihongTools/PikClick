# PikClick v2.1.3

## Changes
- Ice-blue-white main screen with stacked permission rows and updated overlay/accessibility icons.
- Decorative timer scale and editable seconds panel, targeting width:height 1.77:1 at normal text size; larger text can grow and scroll.
- Clear explanation of the two user-triggered taps; existing input bounds and click logic retained.
- Support development opens https://yihongcho.bobaboba.me.
- Explicit Traditional Chinese resources prevent English fallback when English is the secondary system language.

## Evidence and limits
- Version 2.1.3 / code 24. Locally signed APK and SHA-256 are in dist/.
- 10 JVM unit tests and 4 Android 13 emulator instrumentation tests passed during implementation. These cover delay rejection/acceptance, normal-size panel ratio, support intent URI, and Chinese/English/mixed system-language resource loading.
- Signed Release UI inspected at 1080×2340 portrait, 2340×1080 landscape, and font scale 1.3. Floating-button display observed on emulator; full two-tap E2E not performed.
- Physical phone updated in place from 2.1.2 / 23 to 2.1.3 / 24; package version and successful Activity launch confirmed. No claim of full physical-device acceptance.
- Runtime matrix for Android 8/11/15, OEM power management, TalkBack and support-site loading remain unverified.
- Launcher artwork and application ID retained. The release APK is the same file installed on the phone, not an unsigned CI artifact.
